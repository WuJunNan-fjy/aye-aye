# 部署界面体验优化

## 截图评审问题

1. 项目导航在侧栏与正文重复，信息结构没有区分总览与项目详情。
2. 双栏布局在单项目场景严重失衡，配置表单过长，将历史记录挤出首屏。
3. 首页宣传标题大于项目身份，缺少清晰的当前项目和操作焦点。
4. 部署按钮禁用时没有集中的原因说明；服务器状态和地址重复出现。
5. 可选部署要求始终展开，模型设置与主流程争夺注意力。
6. 侧栏所有项目和记录默认展开，缺少当前位置；“新建部署”的实际行为是返回首页。
7. 字号、灰度和按钮样式缺少统一层级，文本链接过多，窄窗适配不足。

## 实施方案

- 分离项目总览与项目工作台：总览负责选择/添加，工作台负责部署与查看记录。
- 侧栏保留项目导航，只展开当前项目的近期任务；清晰标识当前项目与记录。
- 工作台顶部展示项目名称和路径；部署面板压缩为目标服务器、准备检查、操作栏。
- 模型与权限以准备状态展示，并提供对应设置入口；禁用按钮旁说明当前缺少什么。
- 补充要求使用折叠区；部署记录紧接面板，空状态给予具体说明。
- 按用户 2026-10-17 的要求保留原有黑白灰风格：主操作、图标、选中项、准备状态与焦点均采用中性色；统一字号、边框与间距，兼容浅色、深色和窄窗口。
- 保持一键部署请求、权限规则、原任务上下文和用户数据不变。
