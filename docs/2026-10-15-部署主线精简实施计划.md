# 一键部署主线精简实施计划

日期：2026-10-15  
开发分支：`codex/deployment-first`

## 产品目标

aye 的主线是把用户的本地项目部署到 Linux 服务器。用户从项目出发，选择服务器，启动部署，查看进度、处理审批与失败，获得经过验证的结果。

AI 对话、SSH、文件操作和诊断为这条流程服务。保留现有部署工具和权限约束，不因界面精简放宽审批，也不把“启动任务”描述为“部署成功”。

## 本次交付范围

1. 增加项目首页：展示已登记项目、目标服务器、模型准备状态和项目关联的任务记录；提供选择本地项目、启动部署和继续已有任务的入口。
2. 侧栏改为项目与部署记录导航。普通用户不再需要在对话、观测两个一级区域之间切换；历史未关联项目的会话仍可访问。
3. 部署详情保留 AI 对话、阶段进度、审批、停止、恢复和错误信息。进入部署时可靠传递项目，并在刷新、重开任务时恢复部署上下文。
4. 终端与远程文件放入详情的高级操作，默认收起，不再因连接服务器而自动展开。操作记录和 Trace 放入诊断入口，底层审计和事件存储保留。
5. 移除首页通用巡检、清理磁盘等快捷入口；移除普通设置中的搜索服务配置，并停止给部署 Agent 注册通用联网搜索工具。多模型与权限配置通过高级入口访问。
6. 更新 README 和本计划的执行记录，完成前端构建、桌面构建及与变更相关的后端回归验证。

## 实施顺序与验收

- [x] A. 项目与任务数据：会话列表提供可选的项目标识与名称，兼容已有无项目记录；查询不得因已删除项目而丢失历史会话。
- [x] B. 项目首页与导航：首次进入项目首页；空项目、加载失败、无服务器和无模型都有明确操作入口；启动部署前选择项目和服务器，不默默发出请求。
- [x] C. 部署上下文：新任务携带选中项目、服务器及部署标记；刷新、切换任务不会串项目；运行中不能更换项目或服务器影响该任务；原有只读模式不被自动提升权限。
- [x] D. 界面减法：通用运维入口退出首页；终端/文件默认收起；诊断和高级模型/权限配置仍可找到；联网搜索退出默认工具集。
- [x] E. 验证与文档：关键数据关联和部署上下文有针对性验证；前端、桌面构建通过；后端相关回归通过；检查最终差异与未跟踪文件，记录未验证的真实环境项目。

## 本次不扩展的能力

- 不新增支持的项目类型、集群、多环境流水线或复杂编排。
- 不在这一轮界面精简中实现新的发布版本管理与失败回滚机制；它们作为部署可靠性的下一阶段单独设计，现有能力不得宣传为已经支持自动回滚。
- 不删除用户已有项目、聊天记录、主机配置、审计或数据库。
- 不连接真实服务器、不执行真实部署、不发布 Release、不推送分支。

## 后续部署可靠性工作

确定优先支持的项目类型后，补齐环境预检、构建产物校验、版本目录、更新切换、启动等待、可配置健康检查和失败恢复。真实 Windows 安装、测试主机端到端部署及跨版本更新仍需要单独验收。
