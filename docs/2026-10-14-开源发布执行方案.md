## 目标与范围

首发目标：陌生用户能在 Windows x64 上安装应用，配置自己的模型与测试主机，完成一次经过审批的服务器操作，并知道数据存储位置和当前限制。

首发按早期版本发布。优先修复公开内容、安全承诺和构建可靠性，不增加新产品功能，不扩展其他平台。

本方案中的完成状态以实际验证为准。已有文档和本地旧测试报告不作为本次验收通过的证据。

## 发布步骤

1. 确认前三阶段的阻断项完成，整理 CHANGELOG 与已知限制。
2. 在确认的目标仓库配置 CI、分支保护与私密漏洞报告；检查来源说明和公开历史。
3. 确认发布版本与标签，生成草稿 Release，检查安装包、更新描述文件与校验值。
4. 维护者看过具体仓库内容和安装包验收结果后，再公开仓库或发布 Release。

本方案不授权改写 Git 历史、强制推送、操作真实服务器或正式发布；这些动作需要确定具体对象与执行方式。已授权的本地检查、修复、文档整理和测试可以继续。
