## 1. 产品定位（一句话）

**aye-aye 是对话式 Linux 服务器助手（桌面应用）**：用自然语言对话驱动 AI 帮用户运维远程服务器，并把本地项目一键构建、上传、部署上线。

瘦身后的产品只有三件事：

1. **主机连接 + 交互式终端**（SSH，xterm.js）——用户对 AI 不放心时的保底手段；
2. **对话式 AI 运维**（终端/文件操作、审批、可中断可恢复）——核心体验；
3. **一键部署链路**（选项目 → 看懂项目 → 本机构建 → SFTP 直传 → 远程启动探活，7 阶段卡片）——唯一的护城河，Claude Code / dsh / opencode 都没有。

目标用户：不懂代码、但需要把项目跑上服务器的小白用户；以及需要一个顺手的 AI 运维终端的开发者。

**明确不是**：Coding Agent（不做本地代码开发助手）、不做 Web 服务、不做运维平台。

## 2. 非目标清单（永久不做，防止功能膨胀）

以下能力来自 dsh-desktop / Claude Code 等 Coding Agent 的军备竞赛，与本产品定位无关，任何人（包括未来的自己）提需求一律进"也许有一天"清单：

- MCP、Hooks、定时任务 / cron、webhook 触发
- 多 Agent 协作 / Agent Teams、LSP、git worktree、代码沙箱
- 插件 / 技能市场、Skills 体系、ACP
- Docker / docker-compose / systemd 部署（部署"第二刀"再按真实数据决定，不提前做）
- 远程数据库初始化、域名 / HTTPS / 反代配置、多主机批量部署
- Web 版、移动端、i18n、局域网远控、多 Profile、OAuth / 本地模型
- 托盘之外的桌面花活（窗口材质、侧边栏浏览器、Computer Use、手机远控）

## 3. 精简计划（少而精）

### 3.1 保留的六大件（一个都不能再少）

1. 主机管理与连接（密码 / 密钥 / TOFU / 多主机切换）
2. 交互式终端（WebSocket + xterm.js）
3. 对话 Agent 主链路（流式、停止、审批弹窗、权限模式、todo、ask_user、事件溯源 + 冷恢复、插话）
4. 文件管理（文件树、编辑器、上传下载、分片续传）
5. 一键部署全链路（工作区、本机异步执行 + 命令分级、7 阶段卡、SFTP 直传、远程启动探活）
6. 最小设置与可追溯（模型供应商配置、会话列表、Trace 页、审计台账）

## 4. 开源计划

### 4.1 形态

- 协议：**MIT**（依赖全部兼容：Spring Boot / Jackson / sqlite-jdbc / JSch / React / AntD / xterm.js / Electron 均为宽松许可）
- 主仓库放 **GitHub**（面试场景可访问性 + 国际观感），Gitee 做镜像
- **新建干净仓库、不带 git 历史公开**，不做历史清洗（当前 107 个提交中真实 IP 贯穿，清洗成本高于重开）；旧 Gitee 仓库转私有或删除

### 4.2 公开前必做（阻断项）

1. 🚨 **服务器安全处置（与开源无关，但必须最先做）**：历史文档与 `legacy/backend-ts/.env`（被 git 追踪）中出现过公网 IP `81.70.233.174` 与 Redis 弱密码 `123456:6379`。立即：Redis 改强密码或仅 bind 127.0.0.1 + 防火墙关 6379；检查服务器是否已被入侵（authorized_keys / crontab / Redis 异常 key）
2. 新仓库内容筛选：排除 `.git`、`build/`、`.aye*`、legacy、v1 前端、临时 html；全部真实 IP 用文档示例地址替换
3. `git rm --cached legacy/backend-ts/.env`（.gitignore 已忽略但文件仍在索引中）
4. 补 LICENSE（MIT）、开源版 README（定位 + 架构图 + GIF 演示：添加主机 → 对话运维 → 完整部署 + 三条命令内的快速开始 + 技术亮点 + 诚实 Roadmap）
5. 移除 vendor 商标 SVG（deepseek / 通义 / 小米 logo），改文字
6. 代码来源措辞：README 不再写"翻译自 DeepWork"，改为"参考其思路独立实现"，并确保 ai-core 确为按理解重写
7. 最小 CI：GitHub Actions 跑 `mvn test` + 前端 `tsc && vite build`，README 挂 badge
8. 在干净机器上照 README 走一遍启动流程（JDK17 + Maven + Node + pnpm）

### 4.3 开源心理预期

- 垂直工具 + 无推广，预期 Star / Issue 接近 0，属正常；开源目的是**面试可信度**，不是做社区
- README 标注 alpha / 个人项目 / 欢迎 PR 不保证响应时效，不背维护包袱
- API Key 在用户自己手里，本产品不代理模型请求，无账单与密钥连带责任
